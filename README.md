# Bài tập lập HSMT theo Mẫu 5A

## Cấu trúc
- `.claude/skills/hsmt-mau-5a/`: skill lập HSMT (Claude Code tự nhận khi mở thư mục này)
- `dau_vao/`: Mẫu 5A, RFP, tham số chủ đầu tư. Thay file ở đây khi làm gói thầu khác
- `hsmt_lam_viec/`: file trung gian, skill tự tạo
- `ket_qua/`: file HSMT cuối, skill tự tạo

## Chuẩn bị (làm một lần)
1. Cài Python 3.8 trở lên.
2. Mở terminal trong VS Code (Ctrl + `), chạy: `pip install -r requirements.txt`
3. Cài tiện ích Claude Code cho VS Code và đăng nhập.

## Sử dụng
Mở thư mục này trong VS Code (File > Open Folder), mở khung Claude Code, gõ:
`Lập HSMT theo Mẫu 5A từ RFP và tham số trong thư mục dau_vao`
